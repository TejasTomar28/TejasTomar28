## 🚀 Featured Projects

### 🧠 DKD — Dimaag Ka Darpan

A privacy-focused journaling platform designed to help users capture thoughts, track moods, and reflect on their emotional patterns.

Built around a production-style backend architecture with secure authentication, caching, asynchronous event processing, scheduled workflows, and optional AI-assisted journal analysis.

**Highlights:**
- JWT-based authentication and role-based authorization
- Journal and reflection management
- Redis caching
- Event-driven email processing using Apache Kafka
- Scheduled weekly sentiment reports
- Opt-in AI analysis for journal entries
- Reflection prompts and mood tracking
- API documentation with Swagger/OpenAPI
- Docker and CI/CD integration

**Tech:** Java • Spring Boot • Spring Security • MongoDB • Redis • Apache Kafka • JWT • OpenAI • Docker

---

### 🐦‍⬛ Raven AI — RAG Pipeline

An AI-powered Retrieval-Augmented Generation (RAG) system designed to retrieve relevant information from documents and use that context to generate grounded responses.

The project explores the complete RAG workflow — from document ingestion and processing to retrieval, context construction, and LLM-based answer generation.

**Highlights:**
- Document ingestion and processing pipeline
- Semantic retrieval of relevant document context
- Context-aware LLM response generation
- RAG-based question answering
- API-driven architecture using FastAPI
- Separation of ingestion, retrieval, and generation workflows

**Tech:** Python • FastAPI • RAG • Vector Search • LLM APIs
